    Cómo usarlo

    1. Pulsa Activar cámara y acepta el permiso.
    2. Durante 5 s deja la linterna apagada: se detectan reflejos y luces fijas para ignorarlos.
    3. Enciende la linterna y muévela: el punto más brillante dibuja con el color activo.
    4. Déjala quieta 3 s: se guarda la foto, se limpia el lienzo y el color rota Amarillo → Azul → Rojo.

    Funciona mejor en una habitación con poca luz.

    Indicadores

    • REC — linterna detectada, dibujando.
    • ESPERA / RECALIBRANDO — pausa tras una captura; si aparecen reflejos nuevos se alarga para ignorarlos.
    • STANDBY — esperando a que enciendas la linterna.
