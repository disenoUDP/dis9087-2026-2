# De Python a web

Estos dos proyectos se entregaron en Python y aquí están además en versión web.

## Por qué

La entrega se publica en GitHub Pages, que solo sabe mostrar páginas web. No puede ejecutar Python.

Si se sube el archivo `.py`, el link abre el código escrito como texto: no se ve la cámara ni funciona nada. Para que el proyecto se vea andando desde la URL, tenía que estar hecho con lo que el navegador entiende: HTML y JavaScript.

## Qué se hizo

Se rehízo cada proyecto como página web, manteniendo la misma idea y los mismos resultados. La cámara ahora la pide el navegador, el dibujo aparece en la página y las capturas se descargan.

Los archivos `.py` originales siguen aquí, nadie los borró. Ahora hay dos versiones: la de escritorio y la que se puede abrir con un link.

## Lo que hay en cada carpeta

- `MediaPipe_Practice` (Vargas): seis experimentos con cámara, cada uno en su página, más un índice que los enlaza.
- `Open-CV-victoriano`: la app de dibujo con luz, en una sola página.

## Detalles a tener en cuenta

- Cada página parte con un botón porque el navegador siempre pide permiso antes de encender la cámara.
- Las capturas no se guardan solas en una carpeta: el navegador las ofrece como descarga.
- La fluidez depende del computador de quien abre el link.
