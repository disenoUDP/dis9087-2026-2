MediaPipe Practice

Experimentos con la cámara web usando MediaPipe. Cada página pide permiso para usar la cámara.

  • Análisis facial — mide distancias de ojos, cejas, boca y nariz.
  • Analizador de expresiones — cuenta parpadeos, sonrisas, cejas y más.
  • Filtro pixelado — pixela el área entre pulgares e índices de ambas manos.
  • Instrumento facial — la boca controla el tono y los ojos el volumen.
  • Sintetizador de manos — mano derecha: tono, mano izquierda: eco.
  • Estudio electropop — cada dedo levantado dispara un sonido.
