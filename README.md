## reglas clase

1. horario clase: la clase empieza a las 10, pasamos lista 10:15
2. oficio digital: las entregas deben tener los nombres estipulados
3. respeto: velar por el respeto de todas y todos en clases y tareas
4. correos y consultas: el único canal de comunicación es correo y canvas
5. horarios de entrega: horarios establecidos son sagrados y no se mueven. Atraso implica descuento en la nota
6. plagios y citas: toda información presentada debe incluir su origen o cita
7. uso de IA: cuando se promueva su uso se debe declarar. Se debe respetar cuando se solicita su no uso
8. registro audiovisual: deben contar con una bitácora con registro audiovisual de cada una de las actividades en clase y fuera de ella
